2. Exercise Redis queue recovery, scheduler/API/Fly overlap, lease loss, cancellation, checkpoint resume, and retention behavior with real shared Redis and Supabase services. A crash within a graph node can repeat that node's external calls, so validate provider/idempotency behavior.
3. Restore GitHub Actions billing and obtain a successful full CI run on current HEAD; then deploy to staging and verify readiness, provider integration, migrations, alerts, and recovery under dependency outages. Run #48 Docker build evidence is from an earlier revision and does not replace this gate.
4. Expand the hand-authored synthesis eval corpus, obtain blinded domain-expert review, calibrate labels against human judgments, and add deployed-provider tests before enabling synthesis for a production audience. Keep `RESEARCH_SYNTHESIS_ENABLED=false` until those checks pass.
5. Complete the implementation-plan approval and isolated execution workflow before enabling paper-to-code execution; keep arbitrary execution disabled until that review is complete.
6. Verify invitation SMTP/template/redirect configuration and real delivery/acceptance in staging; finish member account discovery and remaining collaboration UX if they are required for the release scope.
7. Complete the remaining product scope in `update.md`: verify gated multi-step research-plan execution in staging, implement opt-in external delivery controls, and establish a full reliability/quality evaluation baseline. OCR is implemented as an opt-in local path but still needs Docker and staging verification. Plan execution defaults off and needs recovery, project-membership revocation, rate/budget, cancellation, and quality exercises before enablement. Synthesis is gated/provisional; project PDF text is excluded from synthesis and model review does not establish claim correctness. Comparison dimensions still use abstracts.
The code and local migrations are not evidence that staging or production behavior is safe. Do not describe Zenith as production-ready until the release blockers have verified evidence.
