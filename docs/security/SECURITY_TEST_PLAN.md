# Security Test Plan

Regression cases (all in `backend/tests/test_security.py` or follow-ups): alg=none rejected; wrong iss/aud rejected; unknown-kid JWKS refetch; cross-user run streaming → 404; reconnect does not restart orchestrator; SSRF private/loopback/metadata URLs blocked; unknown model override rejected; upstream DB errors not leaked to client. Invitation tests cover owner-only creation/list/resend/revoke, role allowlist, email normalization, one active invitation per email across projects, no membership before acceptance, Auth Admin failure, callback HTTPS, email-confirmation and matching identity checks in the acceptance RPC, atomic/idempotent acceptance, and preserving an existing member role. Manual/periodic: RLS owner/member/editor/viewer/outsider/anon matrix against staging Supabase; test direct PostgREST access to active and soft-deleted projects, notes, source rows, memberships, project documents and page text (migration 0013), invitations (migration 0014), runs, and events; test verified matching/mismatched/unverified invite acceptance, cross-project duplicate prevention, expiry, revoke, resend, existing member/owner role preservation, and actual email callback delivery; pentest SSE token + proxy headers; dependency/container scans in CI.
